Mandatory release gates

Editable evidence / status

Gate logic

READY

All mandatory independent gates pass, every critical matrix row has its required evidence and regression check, and deployed hash matches the proposed release.

HOLD

Any mandatory check is unknown, blocked or missing qualified evidence. An unknown is never a pass.

FAIL

Any mandatory gate fails, or any critical test records a failure in a required evidence channel.

Regression

A fix is not closed until retested on the same failing environment, then on relevant neighboring environments and the canonical live build.
