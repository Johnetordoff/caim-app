Frames — click any thumbnail

Touch: one finger draws; two fingers pan and pinch-zoom the picture (not the webpage); tap Fit view to reset. Tap a thumbnail to edit it. “Insert blank after” places a new frame immediately after the selected one. Drag thumbnails to reorder on desktop, or use Move ← / → on mobile. Keyboard: ← / → to navigate (outside fields), Ctrl/Cmd+Z to undo.

Animation & export

Frame timing

Original GIF frame durations are retained when imported (in 10 ms increments).

Frames from files

Import PNG, JPEG, WebP or BMP as an animation frame. Imported images and GIF frames are scaled to fit this canvas. Timing is retained when inserting an animated GIF.

Put words on a frame

Text becomes part of this frame. Undo to change it.

Export animation

GIF uses 256 colors. Transparent pixels are preserved; some colors are approximated. Large exports can be slow.

Convert / export images

When converting an animated GIF into a still-image format, export the selected frame or all frames as a numbered sequence.
